
# PCI Colombo – Smart Pest Control Service Management System

## Project Information
- Institute: Lanka Nippon BizTech Institute (LNBTI)
- Module: ICT2410 Software Development Group Project
- Team: Group F

## Project Overview
An integrated web and mobile system for managing pest control
service requests, quotations, scheduling, employee assignments,
inventory, chemical safety, invoices, and payments.

## Technology Stack
- Frontend (Web): React.js
- Frontend (Mobile): React Native
- Backend: Node.js + Express.js
- Database: MySQL
- Version Control: Git and GitHub
